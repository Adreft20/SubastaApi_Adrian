PASOS PARA ABRIR EL PROYECTO
-----------------------------
 
1. Clona el repositorio (solo la primera vez):
   git clone https://github.com/Adreft20/SubastaApi_Adrian.git
 
2. Entra a la carpeta del proyecto:
   cd SubastaAd
 
3. Instala las dependencias (solo la primera vez):
   npm install
 
4. Corre el proyecto:
   npm run dev
 
5. Abre tu navegador en:
   http://localhost:5173
 
 
PARA CERRAR EL PROYECTO
------------------------
En la terminal presiona Ctrl + C
 
 
PARA ACTUALIZAR CAMBIOS DEL REPOSITORIO
-----------------------------------------
Cada vez que haya cambios nuevos ejecuta:
   git pull
   npm run dev
 
 
RUTAS DISPONIBLES
-----------------
- http://localhost:5173/         -> Login
- http://localhost:5173/signup   -> Registro
